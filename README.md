# Voice Assistant

A personal voice assistant powered by LiveKit agents and various AI plugins.

## Installation

1. Clone the repository.
2. Install the required dependencies:
   ```bash
   pip install -r requirements.txt
   ```

## Usage

1. Populate the `.env` file with your API keys.
2. Run the application:HELP 
   ```bash
   python AGENT.py
   ```

## Configuration

The following environment variables need to be set in the `.env` file:

- `LIVEKIT_API_KEY`
- `LIVEKIT_API_SECRET`
- `LIVEKIT_URL`
- `DEEPGRAM_API_KEY`
- `CARTESIA_API_KEY`
- `OPENAI_API_KEY`
- `GOOGLE_API_KEY`
- `GOOGLE_CSE_ID`
